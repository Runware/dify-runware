# Privacy Policy — Runware (Dify plugin)

This plugin connects Dify to Runware's OpenAI-compatible inference API. It does not add any data collection of its own.

## What the plugin does

When you use a Runware model in Dify, the plugin forwards your request — the prompt / chat messages and the generation parameters you set — to the Runware API (https://api.runware.ai/v1) and returns the model's response. Requests are authenticated with the Runware API key you configure in Dify.

## Data the plugin collects

None. The plugin stores no personal data, performs no analytics or tracking, and transmits data to no third party other than Runware — and only as part of the inference requests you initiate.

## Credentials

Your Runware API key is stored and encrypted by your Dify instance. The plugin reads it only to authenticate calls to the Runware API; it never logs the key or sends it anywhere else.

## Third-party processing (Runware)

The prompts and parameters you send are transmitted to and processed by Runware to generate responses. That processing is governed by Runware's own privacy  policy:

- Runware Privacy Policy: https://runware.ai/privacy
- Runware Terms of Service: https://runware.ai/terms

Review Runware's policy to understand how it handles the data you send.
